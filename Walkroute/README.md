# Walk Rally — ระบบแจ้งการเดินฐาน

เว็บหน้าเดียว (static) สำหรับกิจกรรม Walk Rally **16 กลุ่ม / 8 ฐาน / 8 รอบ**
ใช้แขวนบน GitHub Pages ได้ทันที ไม่ต้อง build ไม่ต้องมีเซิร์ฟเวอร์

## ความสามารถ

| แท็บ | ใช้ทำอะไร |
|---|---|
| 🏳️ **มุมมองฐาน** | เลือกฐานประจำตัวจาก dropdown (1–8) → เลือกรอบ (1–8) → ระบบแจ้งคู่ที่มาแข่ง เช่น `6B vs 7A` |
| 👣 **เส้นทางกลุ่ม** | เลือกกลุ่ม (1A–8B) แล้วดูลำดับการเดินฐานทั้ง 8 รอบ เช่น `1A: 2,3,5,7,6,8,4,1` |
| 📋 **ตารางรวม** | ตารางทุกฐาน × ทุกรอบ ในหน้าเดียว (ไฮไลต์ฐานที่เลือกไว้) |

- **แตะที่ชื่อกลุ่ม** (เช่น `1A` หรือ `3B`) ในการ์ดคู่แข่งขัน → เด้ง **ภาพฐานที่กลุ่มนั้นต้องไปในรอบถัดไป** พร้อมเลขฐานตัวใหญ่
- ฐาน/รอบ/กลุ่มที่เลือกไว้ล่าสุด ถูกจำไว้ในเครื่อง (localStorage) เปิดใหม่ก็อยู่ที่เดิม — เหมาะกับกรรมการที่ประจำฐานเดิมทั้งวัน
- ออกแบบสำหรับมือถือและไอแพดโดยเฉพาะ: ปุ่มใหญ่กดง่าย, dropdown ใช้ตัวเลือกมาตรฐานของ iOS/iPadOS, ธีมสว่าง/มืดตามเครื่อง

## ไฟล์ที่ต้องอัปโหลดขึ้น GitHub

```
index.html      ← ตัวเว็บทั้งหมด (จำเป็น)
.nojekyll       ← จำเป็น กัน GitHub Pages ประมวลผลไฟล์ผิดพลาด
images/1.jpg    ← ภาพฐาน 1–8 (นามสกุลผสมกันได้)
images/2.jpg
   ...
images/8.jpg
README.md       ← ไม่จำเป็นต่อการทำงาน แต่ควรมีไว้เป็นคู่มือ
```

ไฟล์ `.xlsx` **ไม่จำเป็น** ต้องอัปโหลด (ข้อมูลถูกฝังใน `index.html` แล้ว) แต่เก็บไว้ใน repo ก็ได้เผื่ออ้างอิงภายหลัง

### ถ้าไฟล์ภาพไม่ครบ

ระบบไม่พังและใช้งานได้ตามปกติ โดยจะเตือน 2 จุด:
- **แถบเตือนด้านบนหน้าเว็บ** เช่น “⚠️ ยังไม่มีไฟล์ภาพ 2 ฐาน: ฐาน 5, 7” (ถ้าครบทุกฐาน แถบนี้จะไม่ขึ้นเลย)
- **ในป๊อปอัป** เมื่อกดกลุ่มที่ต้องไปฐานซึ่งยังไม่มีภาพ จะขึ้น “⚠️ ยังไม่มีไฟล์ภาพของฐานที่ 5” พร้อมบอกชื่อไฟล์ที่ต้องอัปโหลด

ชื่อไฟล์ต้องเป็นเลขฐาน `1`–`8` เท่านั้น นามสกุลผสมกันได้ (`.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, `.svg`)
ดูรายละเอียดใน [images/README.md](images/README.md)

## วิธีขึ้น GitHub Pages

```bash
git init
git add .
git commit -m "Walk rally base schedule site"
git branch -M main
git remote add origin https://github.com/<user>/<repo>.git
git push -u origin main
```

จากนั้นที่ repo → **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)`**
เว็บจะขึ้นที่ `https://<user>.github.io/<repo>/`

ทดสอบในเครื่องก่อนได้ด้วย:

```bash
python3 -m http.server 8000
```

## ที่มาของข้อมูล

ตารางฝังอยู่ในตัวแปร `SCHEDULE` ใน `index.html` ดึงมาจากชีต **ตารางหลัก** ของไฟล์
`ตารางแข่งขันเข้าฐาน_16ทีม_8ฐาน_8รอบ.xlsx`
เส้นทางรายกลุ่มคำนวณจากตารางเดียวกัน จึงไม่มีทางขัดกันเอง

ตรวจสอบเงื่อนไขแล้ว: ทุกฐานมี 2 กลุ่มทุกรอบ · ทุกกลุ่มเข้าครบ 8 ฐาน ฐานละครั้ง · ไม่มีคู่ซ้ำ · ไม่มีคู่จากกลุ่มรหัสเดียวกัน

### ถ้าต้องแก้ตาราง

แก้ไฟล์ Excel แล้วรันสคริปต์นี้เพื่อสร้าง `SCHEDULE` ก้อนใหม่ไปแทนใน `index.html`:

```bash
python3 -c "
import openpyxl, re
ws = openpyxl.load_workbook('ตารางแข่งขันเข้าฐาน_16ทีม_8ฐาน_8รอบ.xlsx')['ตารางหลัก']
for r in list(ws.iter_rows(values_only=True))[4:12]:
    n = re.search(r'\d+', r[0]).group()
    print('  %s: [%s],' % (n, ','.join('[\"%s\",\"%s\"]' % tuple(x.strip() for x in c.split('vs')) for c in r[1:9])))
"
```
