# โฟลเดอร์ภาพฐาน

วางไฟล์ภาพของแต่ละฐานไว้ในโฟลเดอร์นี้ โดยตั้งชื่อไฟล์เป็นเลขฐาน `1` – `8`

```
images/
 ├─ 1.png
 ├─ 2.jpg
 ├─ 3.jpeg
 ├─ ...
 └─ 8.webp
```

- นามสกุลไฟล์ผสมกันได้ ระบบจะไล่หาอัตโนมัติตามลำดับ:
  `.png → .jpg → .jpeg → .webp → .JPG → .PNG → .JPEG → .WEBP → .gif → .svg`
- ถ้ายังไม่มีไฟล์ของฐานใด เว็บจะขึ้นข้อความแจ้งแทน (ไม่พัง)
- แนะนำย่อภาพให้กว้างไม่เกิน ~1600px เพื่อให้โหลดเร็วบนมือถือ
