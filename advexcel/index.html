ชีต 05_สรุปรวม — สี่ตารางเป็นหนึ่งเดียว

1
ต่อทั้งสี่ตารางเข้าด้วยกัน เขียนแค่ชื่อตาราง=VSTACK(คะแนน252240,คะแนน252211,คะแนน255231,คะแนน252212)
2
กรองตามเกรดที่เลือกในช่อง C4=LET(all,VSTACK(คะแนน252240,คะแนน252211,คะแนน255231,คะแนน252212),FILTER(all,CHOOSECOLS(all,14)=$C$4,"ไม่พบ"))
3
แจกแจงเกรดข้ามทุกรายวิชา ด้วย GROUPBY=LET(all,VSTACK(คะแนน252240,คะแนน252211,คะแนน255231,คะแนน252212),GROUPBY(CHOOSECOLS(all,14),CHOOSECOLS(all,2),COUNTA,0,1,-2))
4
ตารางไขว้ รายวิชา x เกรด ด้วย PIVOTBY=LET(all,VSTACK(คะแนน252240,คะแนน252211,คะแนน255231,คะแนน252212),PIVOTBY(CHOOSECOLS(all,1),CHOOSECOLS(all,14),CHOOSECOLS(all,2),COUNTA,0,1))
ข้อควรระวัง ถ้าจะเอาผลของ GROUPBY ไปกรองต่อ ต้องตั้ง total_depth = 0 มิฉะนั้นแถวผลรวมจะติดไปด้วยและทำให้ตัวเลขผิด
โจทย์รวมทุกเครื่องมือ

หานิสิตที่ได้ F มากกว่าหนึ่งรายวิชา

รายชื่อนี้คือสิ่งที่อาจารย์ที่ปรึกษาต้องได้รับเพื่อติดตามเป็นรายบุคคล

1
รวมทุกวิชา ตั้งชื่อว่า allall, VSTACK(คะแนน252240,คะแนน252211, คะแนน255231,คะแนน252212)
2
คัดเฉพาะแถวที่ได้ F ตั้งชื่อว่า ff, FILTER(all,CHOOSECOLS(all,14)="F")
3
นับว่าแต่ละคนได้ F กี่วิชา ตั้งชื่อว่า gg, GROUPBY(CHOOSECOLS(f,10), CHOOSECOLS(f,14),COUNTA,0,0,-2)
4
เอาเฉพาะคนที่มากกว่า 1 โดยชี้ที่คอลัมน์จำนวนของ gFILTER(g,CHOOSECOLS(g,2)>1,"ไม่มี")
สูตรเต็มที่ประกอบเสร็จแล้ว
=LET( all, VSTACK(คะแนน252240,คะแนน252211,คะแนน255231,คะแนน252212), f, FILTER(all,CHOOSECOLS(all,14)="F"), g, GROUPBY(CHOOSECOLS(f,10),CHOOSECOLS(f,14),COUNTA,0,0,-2), FILTER(g,CHOOSECOLS(g,2)>1,"ไม่มีนิสิตที่ได้ F เกินหนึ่งวิชา") )

ทำไม GROUPBY ต้องใส่ 0,0

field_headers = 0 เพราะ CHOOSECOLS ส่งมาแต่เนื้อข้อมูล ไม่มีหัวตาราง และ total_depth = 0 ไม่เอาแถวรวม เพราะแถวรวมจะกลายเป็นข้อมูลปลอมเมื่อนำไป FILTER ต่อ

CHOOSECOLS ทำหน้าที่อะไรตรงนี้

ผลของ GROUPBY มีสองคอลัมน์คือ ชื่อ และ จำนวน · CHOOSECOLS(g,2) คือการหยิบคอลัมน์จำนวนออกมาเป็นเงื่อนไขให้ FILTER

06 จัดวิชา

วิชาไหนเปิดได้ ต้องเปิดกี่หมู่

สามเทคนิคที่ควรจำไปใช้
  • REGEXEXTRACT — เมื่อต้องดึงสิ่งที่มี รูปแบบ ชัดเจนออกจากข้อความมั่ว ๆ
  • MAXIFS — เมื่อต้องเลือกรายการล่าสุดของแต่ละกลุ่มโดยไม่ลบข้อมูลเดิม
  • COUNTIFS + * — เมื่อสิ่งที่ค้นซ่อนอยู่กลางข้อความที่รวมหลายค่าไว้
ข้อควรระวังที่เจอบ่อย
  • ลืมเงื่อนไข ล่าสุด = ใช่ ยอดผู้เลือกจะเกินจริงจากการนับซ้ำ
  • ลืม IFERROR ครอบ REGEXEXTRACT แถวที่ไม่ได้ตอบจะขึ้น #N/A แล้วลามทั้งสาย
  • นับผิดภาคเรียน เพราะเลือกคอลัมน์ รหัสภาคต้น กับ รหัสภาคปลาย สลับกัน
