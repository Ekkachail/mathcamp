## วิธีนำขึ้น GitHub Pages

### 1. สร้าง repository
เข้า <https://github.com/new> ตั้งชื่อเช่น `advexcel-slides` เลือก **Public** แล้วกด Create

### 2. อัปโหลดไฟล์
วิธีง่ายที่สุดคือลากไฟล์ทั้งโฟลเดอร์นี้ไปวางในหน้า repository ที่เพิ่งสร้าง แล้วกด Commit changes

หรือถ้าถนัดใช้คำสั่ง

```bash
cd advexcel-slides
git init
git add .
git commit -m "เพิ่มสไลด์บรรยาย Advanced Excel"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/advexcel-slides.git
git push -u origin main
```

### 3. เปิด GitHub Pages
ในหน้า repository ไปที่ **Settings → Pages**
- Source เลือก **Deploy from a branch**
- Branch เลือก **main** โฟลเดอร์ **/ (root)** แล้วกด Save

รอประมาณ 1–2 นาที จะได้ลิงก์

```
https://<ชื่อผู้ใช้>.github.io/advexcel-slides/
```

ลิงก์นี้เปิดสไลด์ได้ทันทีจากทุกเครื่อง ไม่ต้องดาวน์โหลด

## การแก้ไข

### เปลี่ยนลิงก์แฟ้มเอกสาร
แก้ข้อความ `https://shorturl.nu.ac.th/ni4dmi` ในสไลด์ที่ 2 ของ `index.html`
และเปลี่ยนรูป QR ที่ฝังอยู่ในสไลด์เดียวกัน

### เปลี่ยนสีหรือฟอนต์
ตัวแปรสีทั้งหมดอยู่ในบล็อก `:root` ต้นไฟล์ ฟอนต์โหลดจาก Google Fonts
(Kanit สำหรับหัวเรื่อง · Sarabun สำหรับเนื้อความ · JetBrains Mono สำหรับสูตร)
หากเปิดในเครือข่ายที่บล็อก Google Fonts จะใช้ฟอนต์สำรองในเครื่องแทน
คือ Leelawadee UI บน Windows และ Thonburi บน macOS ซึ่งอ่านภาษาไทยได้ครบ

### อัปเดตไฟล์บน GitHub
แก้ไฟล์แล้ว commit และ push ตามปกติ GitHub Pages จะอัปเดตให้เองภายในไม่กี่นาที

## หมายเหตุ

- ข้อมูลนิสิตในไฟล์ Excel ประกอบทั้งหมดเป็นข้อมูลสมมติที่สร้างขึ้นเพื่อการฝึกอบรม
  รายชื่ออาจารย์และรายวิชาเป็นข้อมูลจริงของภาควิชา
- ฟังก์ชัน `XLOOKUP` `FILTER` `SORT` ใช้ได้ตั้งแต่ Excel 2021
  `VSTACK` `CHOOSECOLS` ต้อง Excel 2024
  `GROUPBY` `PIVOTBY` `REGEXEXTRACT` ต้อง Microsoft 365
  ทุกสไลด์ที่ใช้ฟังก์ชันเหล่านี้ระบุเวอร์ชันกำกับไว้แล้ว
  และเอกสารบรรยายมีภาคผนวก ง รวบรวมวิธีดั้งเดิมที่ใช้แทนได้ครบทุกฟังก์ชัน
